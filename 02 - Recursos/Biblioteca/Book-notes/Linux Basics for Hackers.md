# Linux Basics for Hackers

![Portada de Linux Basics for Hackers](https://covers.openlibrary.org/b/isbn/9781593278557-L.jpg)

**Getting Started with Networking, Scripting, and Security in Kali** — por OccupyTheWeb (OTW), fundador de hackers-arise.com.

## Sinopsis

Introducción a `Linux` orientada explícitamente al pentester, usando `Kali Linux` como distribución de referencia. En vez de enseñar Linux de forma genérica, cada concepto se ancla desde el primer capítulo en tareas reales de un hacker: manipular texto para parsear salidas de herramientas, gestionar procesos y permisos que luego determinan qué se puede escalar, y automatizar con `bash` en vez de repetir comandos a mano.

La segunda parte cubre la capa de red — administración de servicios, captura y manipulación de tráfico — como base para entender qué está pasando por el cable antes de atacarlo. Cierra con seguridad y anonimato del propio operador (gestión de logs, hardening básico, uso de proxies/Tor) y una introducción a `scripting` en `Bash` y `Python` para empezar a automatizar tareas repetitivas.

Es un libro de nivel **fundamentos** — el propio autor lo posiciona como paso previo a sus libros más avanzados de la serie (*Linux Basics for Hackers* → *Getting Started Becoming a Master Hacker*). Para alguien que ya vive en una terminal a diario, el valor está más en la organización pedagógica y en los ejemplos aplicados a seguridad que en contenido nuevo — pero es una referencia sólida para consultar sintaxis de red y scripting sin rodeos.

## Qué cubre el libro

- Sistema de archivos, permisos y gestión de procesos en Linux desde la óptica ofensiva.
- Manipulación de texto (`grep`, `sed`, `awk`) para procesar salidas de herramientas de recon.
- Gestión de paquetes y servicios (instalar, arrancar/parar, `systemd`) en Kali.
- Administración de red: interfaces, `DHCP`, captura de tráfico con herramientas nativas.
- Gestión de usuarios/grupos y variables de entorno relevantes para post-explotación.
- Anonimato y ocultación de rastros: logs, proxies, `Tor`.
- Automatización con `Bash scripting` y una introducción a `Python` para tareas de seguridad.
- Compilación de exploits y gestión de permisos sobre binarios compilados.
