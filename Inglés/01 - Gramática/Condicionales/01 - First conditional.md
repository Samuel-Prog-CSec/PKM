<mark style="background: #ADCCFFA6;">El *first conditional* habla de una posibilidad **real** en el futuro y su consecuencia probable</mark>.

# Estructura

**If + present simple, + will + verbo base.**

*If it **rains**, I**'ll stay** home. If you **study**, you**'ll pass**.*

<mark style="background: #FF5582A6;">Tras `if` NUNCA va `will`</mark>: la condición va en presente, y `will` solo en la mitad del resultado.

# Variantes en la principal

En vez de `will` puede ir otro modal o el imperativo: *If you're tired, you **should** rest. If you see him, **tell** him. If we hurry, we **might** catch the bus.*

# Conjunciones alternativas a if

- **`unless`** = *if not*: *I won't go **unless** you come* (= if you don't come).
- **`as long as` / `provided that`** = siempre que: *You can borrow it **as long as** you return it.*
- **`in case`** = por si acaso (+ presente): *Take an umbrella **in case** it rains.*

# Casos atípicos

- **`if` + present continuous / present perfect** también valen en la condición: *If you**'re looking** for Sam, he's out. If you**'ve finished**, you can go.*

> [!warning]+ Fallos típicos
> - `will` tras `if`: *If it will rain* ❌ → *If it **rains*** ✅.
> - Doble negación con `unless`: *unless you don't come* ❌ → *unless you come* ✅.

> [!warning]+ Trampas de examen ("para pillar")
> - **`unless` = if not**: cuidado con negar dos veces.
> - **`in case` ≠ if**: *in case* es prevención (lo haces antes por si acaso), no condición.
> - Posibilidad real → first; hipótesis irreal → second (ver [[02 - Second conditional]]).

# Ejercicios

> [!question]+ 1. Rellena (first conditional)
> 1. If you ______ (not/hurry), you ______ (miss) the train.
> 2. I ______ (call) you if I ______ (need) help.
> 3. If it ______ (be) sunny, we ______ (go) to the beach.

> [!success]- Solución 1
> 1. **don't hurry / will miss** — 2. **will call / need** — 3. **is / will go**

> [!question]+ 2. Reescribe con unless
> 1. If you don't study, you won't pass. → You won't pass ______ you study.
> 2. I'll be angry if you don't apologise. → I'll be angry ______ you apologise.

> [!success]- Solución 2
> 1. **unless** — 2. **unless**

> [!question]+ 3. Corrige el error
> 1. If it will snow, we'll build a snowman.
> 2. Unless you don't practise, you won't improve.

> [!success]- Solución 3
> 1. If it **snows**, we'll build… — 2. **Unless** you **practise**, you won't improve

> [!question]+ 4. ¿Cuál es la frase CORRECTA?
> 1. (a) If you will come, call me. (b) If you come, call me. (c) If you came, call me.
> 2. (a) Take a coat in case it gets cold. (b) Take a coat if it will get cold.

> [!success]- Solución 4
> 1. **b** — 2. **a**
