<mark style="background: #ADCCFFA6;">`can` / `could` / `be able to` expresan habilidad o capacidad de hacer algo</mark>.

# Presente, pasado y futuro

| Tiempo | Forma | Ejemplo |
| --- | --- | --- |
| Presente | `can` / `am/is/are able to` | I **can** swim. |
| Pasado (habilidad general) | `could` / `was/were able to` | She **could** read at four. |
| Pasado (un logro concreto) | **was/were able to / managed to** | We **were able to** escape. |
| Futuro / infinitivo / otros tiempos | **be able to** | I**'ll be able to** help tomorrow. |

<mark style="background: #FF5582A6;">`can` y `could` no tienen infinitivo ni futuro</mark>: para esos casos es obligatorio `be able to` (*I won't be able to come*, *I'd like to be able to cook*, *I've never been able to sing*).

# could vs was able to (el matiz clave)

- `could` = **habilidad general** en el pasado: *When I was young, I **could** run fast.*
- Para **un logro puntual** (conseguir algo en una ocasión concreta) se usa **`was/were able to`** o **`managed to`**, no *could*: *The exam was hard, but I **was able to** finish it* (no *I could finish it*).

<mark style="background: #8000E1A6;">En **negativa**, esta distinción desaparece: `couldn't` vale para ambos</mark>: *I couldn't open the door* (tanto general como puntual).

# Casos atípicos

- Con verbos de **percepción/entendimiento** (see, hear, feel, understand, remember), se usa `could` incluso para momentos concretos: *I **could** hear a strange noise.*

> [!warning]+ Fallos típicos
> - Usar `could` para un logro único afirmativo: *Yesterday I could pass the exam* ❌ → *I **was able to / managed to** pass* ✅.
> - Futuro con *can*: *Tomorrow I can help* (habla del presente) → para futuro real, *I**'ll be able to** help*.

> [!warning]+ Trampas de examen ("para pillar")
> - **Afirmativa + logro concreto → `was able to / managed to`**; negativa → `couldn't` siempre.
> - **Verbos de percepción → `could`** aunque sea puntual.

# Ejercicios

> [!question]+ 1. Rellena (can/could/be able to)
> 1. When I was young, I ______ run very fast.
> 2. After weeks of practice, she finally ______ (positivo, logro) drive.
> 3. Sorry, I won't ______ attend the meeting.
> 4. I've never ______ (perfect) whistle.

> [!success]- Solución 1
> 1. **could** — 2. **was able to / managed to** — 3. **be able to** — 4. **been able to**

> [!question]+ 2. Elige could o was/were able to
> 1. The firefighters ______ rescue everyone from the building.
> 2. My grandma ______ speak four languages.
> 3. It was foggy, but we ______ find the way home.

> [!success]- Solución 2
> 1. **were able to** (logro puntual) — 2. **could** (general) — 3. **were able to / managed to**

> [!question]+ 3. Corrige el error
> 1. Yesterday I could finish the marathon.
> 2. Next year I can travel abroad.
> 3. She cann't swim.

> [!success]- Solución 3
> 1. …I **was able to / managed to** finish… — 2. …I**'ll be able to** travel… — 3. She **can't** swim

> [!question]+ 4. ¿Cuál es la frase CORRECTA?
> 1. (a) I could to swim when I was five. (b) I could swim when I was five. (c) I can swim when I was five.
> 2. (a) He managed to open the safe. (b) He could open the safe (una vez).

> [!success]- Solución 4
> 1. **b** — 2. **a** (logro concreto)
